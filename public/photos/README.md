# Zdjęcia do pytań

Wrzuć tu zdjęcia do pytań quizowych, np. `public/photos/marta/marta-young.jpg`, i wskaż je
w `questions.json` (w repo backendu) jako `/photos/marta/marta-young.jpg`.

* Format: jpg/png/webp, najlepiej ok. 800 px szerokości (telefony ładują 4 zdjęcia na pytanie).
* `sample/` zawiera zastępcze obrazki używane przez `local_server.py` i testy e2e.
